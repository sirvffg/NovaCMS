# Markdown 编辑器使用指南

## 🎯 新增功能概述

我们的 Markdown 编辑器现在支持更多强大的功能，让您能够更轻松地创建丰富的内容！

---

## 📝 基础编辑功能

### 文字格式化
- **粗体**: 选中文字后按 `Ctrl+B` 或点击工具栏按钮
- **斜体**: 选中文字后按 `Ctrl+I` 或点击工具栏按钮  
- **删除线**: 点击工具栏删除线按钮
- **标题**: 按 `Ctrl+H` 或点击标题按钮

### 列表功能
- **无序列表**: 点击工具栏列表按钮
- **有序列表**: 点击有序列表按钮
- **任务列表**: 点击任务列表按钮，创建可勾选的待办事项

### 代码块
- **行内代码**: 选中文字后按 `Ctrl+Shift+C`
- **代码块**: 选择多行代码后按 `Ctrl+Shift+C`

---

## 🎨 增强功能

### 📊 表格插入
- **快捷键**: `Ctrl+T`
- **工具栏**: 点击表格按钮 📊
- **智能转换**: 如果选中了包含逗号或制表符的文本，会自动转换为表格

### 😊 表情符号
- **快捷键**: `Ctrl+Shift+E`
- **工具栏**: 点击表情按钮 😊
- **自动补全**: 输入 `:smile:` 等表情代码时会有提示

### 🧮 数学公式
- **快捷键**: `Ctrl+Shift+M`
- **工具栏**: 点击计算器按钮 🧮
- **支持类型**:
  - 内联公式: `$E=mc^2$`
  - 块级公式: `$$\sum_{i=1}^{n}$$`

### 🖼️ 媒体上传
- **图片上传**: `Ctrl+Shift+I` 或点击图片按钮
- **视频上传**: 点击视频按钮
- **文件上传**: `Ctrl+Shift+U` 或点击文件按钮

## 🎯 高级技巧

### 1. 智能自动补全
- 输入 `:` 会触发表情符号自动补全
- 输入 `\` 或 `$` 会触发数学公式自动补全

### 2. 数学公式模板
编辑器提供常用数学公式模板：
- 分数: `\frac{a}{b}`
- 开方: `\sqrt{x}`
- 求和: `\sum_{i=1}^{n}`
- 积分: `\int_{a}^{b}`
- 极限: `\lim_{x\to\infty}`
- 矩阵: `\begin{matrix} ...\end{matrix}`

### 3. 表格智能创建
- 选中文本会自动转换为表格
- 支持逗号、制表符分隔的文本
- 自动生成表头和分隔线

### 4. 任务列表
- 使用 `- [ ]` 创建未完成任务
- 使用 `- [x]` 创建已完成任务
- 在预览中显示为可勾选的复选框

---

## 💡 使用建议

1. **快捷键优先**: 熟练使用快捷键可以大大提高编辑效率
2. **预览模式**: 使用并排预览模式实时查看效果
3. **数学公式**: 复杂数学公式建议使用块级格式
4. **表格编辑**: 先在Excel中整理好数据，然后复制粘贴转换
5. **表情使用**: 善用表情符号可以让内容更生动

---

## 🔧 技术支持

如果您在使用过程中遇到问题，可以：
1. 查看编辑器内置的帮助文档（点击工具栏的指南按钮）
2. 使用 `Ctrl+Z` 撤销误操作
3. 使用清理功能去除多余的格式
